# ការគាំទ្រភាសាខ្មែរ — Drag Shelf

ចាប់ពីកំណែ 1.2.0 កម្មវិធី Drag Shelf សម្រាប់ Windows និង macOS គាំទ្រភាសាខ្មែរ និងភាសាអង់គ្លេស។

## ប្ដូរភាសា

- ចុចកណ្ដុរស្ដាំលើរូបតំណាង Drag Shelf នៅជិតនាឡិកា Windows ឬលើរបារម៉ឺនុយ macOS។ ជ្រើស **Language / ភាសា → ភាសាខ្មែរ**។
- អ្នកក៏អាចជ្រើសភាសានៅជ្រុងខាងស្ដាំលើនៃផ្ទាំងការណែនាំបានដែរ។
- ភាសានឹងប្ដូរភ្លាមៗ ហើយជម្រើសរបស់អ្នកត្រូវបានរក្សាទុកសម្រាប់ការបើកលើកក្រោយ។ ជម្រើស «តាមភាសាប្រព័ន្ធ» នឹងប្រើភាសាខ្មែរ បើប្រព័ន្ធប្រតិបត្តិការរបស់អ្នកប្រើភាសាខ្មែរ។

## មុខងារដែលបានបកប្រែ

ធ្នើ ម៉ឺនុយ រូបរាង ពណ៌រំលេច គន្លឹះនៅលើប៊ូតុង ផ្ទាំងការណែនាំ ផ្ទាំងកំណត់ផ្លូវកាត់ ផ្ទាំងរូបថតពីទូរសព្ទ ទំព័រផ្ញើរូបថតលើទូរសព្ទ និងសារកំហុសរបស់កម្មវិធី។ កាលបរិច្ឆេទ ពេលវេលា និងចំនួនត្រូវបានបង្ហាញជាភាសាខ្មែរ។

កម្មវិធីភ្ជាប់ពុម្ពអក្សរ Noto Sans Khmer ដែលអាចប្រើបានដោយមិនចាំបាច់ភ្ជាប់អ៊ីនធឺណិត។ ទំព័រលើទូរសព្ទទទួលពុម្ពអក្សរពីកុំព្យូទ័រតាមបណ្ដាញមូលដ្ឋាន។

ឈ្មោះឯកសារ និងឈ្មោះធ្នើដែលអ្នកបានដាក់ មិនត្រូវបានបកប្រែ ឬប្ដូរដោយស្វ័យប្រវត្តិទេ។ ឈ្មោះធ្នើវែងនឹងបត់ជាបន្ទាត់ថ្មី។ អ្នកអាចអូសរបាររមូរ ដើម្បីមើលធ្នើផ្សេងទៀត ឬឈ្មោះវែងខ្លាំង។

Windows ប្រើ **Ctrl+Shift+F** ដើម្បីបង្ហាញធ្នើ និង **Ctrl** ដើម្បីរក្សាធាតុលើធ្នើនៅពេលអូសចេញ។ macOS ប្រើ **⌥⇧S** និង **⌥**។ ស្លាកគ្រាប់ចុច និងទ្រង់ទ្រាយដូចជា PDF ឬ MB នៅតែប្រើអក្សរស្តង់ដារ។

កម្មវិធីដំឡើង និងផ្ទាំងរបស់ប្រព័ន្ធប្រតិបត្តិការអាចប្រើភាសារបស់ប្រព័ន្ធ។ សេចក្ដីព្រាង Microsoft Store ចាស់នៅតែផ្អាក និងមិនមែនជាកម្មវិធី Electron ថ្មីនេះទេ។
